# Portfólio Pessoal

Este projeto foi desenvolvido como atividade prática utilizando HTML, CSS e JavaScript.

## Objetivo

Criar um site de portfólio pessoal para apresentar:

- informações profissionais
- habilidades
- projetos
- formas de contato

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Página inicial
- Seção sobre mim
- Lista de habilidades
- Área de projetos
- Contato
- Layout responsivo
- Navegação funcional

## Responsividade

O site foi desenvolvido para funcionar em:

- Desktop
- Tablets
- Smartphones

## Publicação

Projeto publicado utilizando GitHub Pages.
